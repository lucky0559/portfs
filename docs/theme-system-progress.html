Feature record · 2026-08-30

Theme follows the hour.

A light counterpart to the portfolio's original dark palette, resolved before paint from local time and superseded by a visitor's explicit choice.

Logo surfaces refined · final browser check pending

Resolution path

The feature avoids theme polling and avoids a wrong-theme body flash by resolving state in the document head.

01

Read preference

Accept only light or dark from local storage.

02

Resolve time

Use light from 07:00 to 18:59 in the visitor's local timezone.

03

Apply before paint

Set root data attributes before the body renders.

04

Respect intent

Persist switch choices and synchronize them across tabs.
